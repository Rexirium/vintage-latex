% Every digit in the table body is computed here at compile time. Change the
% first and last row numbers and the whole page is regenerated.
\begin{luacode*}
function logtable(first, last)
  local rows = {}
  for n = first, last do
    local cells = {}
    for d = 0, 9 do
      local value = n * 10 + d
      local mantissa = math.log(value, 10) % 1
      cells[#cells + 1] = string.format("%05d",
        math.floor(mantissa * 100000 + 0.5))
    end
    -- Tabular difference between the first two entries, in units of the
    -- fifth place. Period tables printed this in a narrow final column.
    local diff = tonumber(cells[2]) - tonumber(cells[1])
    if diff < 0 then diff = diff + 100000 end
    local row = string.format("%d & %s & %d", n,
      table.concat(cells, " & "), diff)
    rows[#rows + 1] = row .. "\\\\"
    if (n - first + 1) % 5 == 0 and n < last then
      rows[#rows + 1] = "\\noalign{\\vskip 2.2pt}"
    end
  end
  tex.print(rows)
end
\end{luacode*}

\footnotesize
The mantissa is printed without its characteristic, which is 3 for every
entry on this page. The column headed D.\ gives the difference between the
first two entries of the row, and decreases down the table as the logarithm
varies more slowly. No figure in the body was typed: a short Lua function
computes each mantissa when the page is compiled, and the table is extended
by changing two numbers in the source. Lining figures were chosen because
old-style figures descend below the baseline and disturb the alignment a
table depends on.
